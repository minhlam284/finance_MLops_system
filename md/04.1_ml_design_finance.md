Finance ML Design

1. Goal

Xây dựng mô hình ML sử dụng các bảng Gold và Feature. Task: Dự đoán một giao dịch sắp tới có phải là gian lận (fraud) hay không.

2. Prediction Setup and Modeling Plan
- Entity: account_id (hoặc transaction_id).
- Label: is_fraudulent (1 = yes, 0 = no).
- Training Data: `ml_fraud_detection_training`.
- Metrics: Precision, Recall, PR-AUC (vì dữ liệu fraud thường rất mất cân bằng).
- SLA: Online inference latency p95 < 200 ms.

7. Pipeline Design (Data + ML)
Pipeline A: Training Pipeline
  1. training_dataset_job
  2. train_job (chạy mô hình baseline, VD: XGBoost)
  3. evaluation_job
  4. model_registry_job
Pipeline B: Real-time Serving Pipeline
  1. streaming_scoring_job (đọc từ topic giao dịch mới nhất)
  2. write_scores_job (ghi fraud_score và action như block/allow)

8. CI/CD Pipeline Design
- Track A: CI/CD cho ML Pipelines (lint, unit tests, pipeline DAG validation).
- Track B: CI/CD cho API Services (canary rollout, health checks cho /score endpoint).

10. Retraining Strategy
- Scheduled: Chạy lại hàng ngày/tuần.
- Triggered: Kích hoạt khi PR-AUC giảm xuống dưới baseline hoặc hệ thống phát hiện feature drift.
